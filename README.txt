iPhone安装（推荐 GitHub Pages 免费部署）：
1. 在 github.com 创建账号并登录。
2. 创建 Public 仓库，例如 strength-journal。
3. 将本文件夹内的5个文件上传到仓库根目录（不是上传zip）。
4. 进入仓库 Settings → Pages → Build and deployment → Deploy from a branch；Branch 选择 main / (root)，保存。
5. 等待部署完成，访问 https://你的用户名.github.io/strength-journal/ 。
6. 用 iPhone Safari 打开该 HTTPS 地址 → 分享 → 添加到主屏幕。
7. 打开主屏幕 App，设置开始日期和医疗许可状态，开始记录。

重要：
- 所有数据默认只存于当前设备本地，GitHub Pages 不接收训练记录。
- 每周从 App 设置页导出 JSON 备份，保存到 iPhone 文件/iCloud Drive。
- 更换手机：在新设备打开 App，设置页导入 JSON 备份。
- 如果未获医生明确许可，上肢动作锁定；下肢训练也应先确认可开展。
- 浏览器和主屏幕应用的数据可能隔离，务必固定在一个入口使用。
- 本 App 不包含自动云同步，不保证系统永不清理本地数据。
